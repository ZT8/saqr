# Around

منصة إماراتية للطلب من السيارة (درايف ثرو افتراضي): العميل يطلب ويدفع من التطبيق، والمنصة تتابع طريقه وتنبّه الفرع قبل وصوله، والموظف يسلّم الطلب لسيارته.

## التشغيل السريع

المتطلبات: Node.js 20 أو أحدث.

```bash
npm run setup     # يثبت الحزم، يبني الواجهات، ويعبي قاعدة بيانات تجريبية
npm start         # يشغل كل شي على http://localhost:4000
```

| الواجهة | الرابط | الدخول التجريبي |
| --- | --- | --- |
| الموقع + انضم كتاجر | `/` و `/join` | — |
| تطبيق العميل (PWA) | `/app` | 0500000004 |
| تطبيق الفرع (تابلت) | `/branch` | 0500000003 (موظف) أو 0500000002 (مالك) |
| لوحة التاجر | `/merchant` | 0500000002 |
| لوحة الأدمن | `/admin` | 0500000001 |

في وضع التطوير رمز التحقق دائماً **1234**. حسابات عملاء إضافية للسوشال: 0500000011 إلى 0500000015.

للتطوير مع تحديث فوري: `npm run dev:server` في نافذة، و `npm run dev:web` في نافذة ثانية، وافتح http://localhost:5173.

## وش فيه

**تطبيق العميل** (`/app`، يتثبت على الجوال كتطبيق)
- الرئيسية: بحث، تصنيفات، ستوريات Around Social، «اطلب بسرعة» لإعادة آخر طلباتك، المفضلة، بطاقات الولاء، جديد في Around، المحلات القريبة حسب موقعك.
- صفحة المحل: المنيو والأكثر طلباً، السلة، طلباتي من المحل، معلومات الفروع والاتجاهات، المفضلة والمشاركة، بطاقة ولاء المحل، ستوريات المحل.
- الدفع: اختيار السيارة، رصيد الهدايا، هدية مشروب أو أكل، مكافأة الولاء، Apple Pay و Google Pay وبطاقة.
- تتبع الطلب لحظياً: «أنا في الطريق» يشارك موقعك، المسافة ووقت الوصول، كم سيارة قدامك، الوصول تلقائي بالسياج الجغرافي (80 م) أو زر «وصلت»، الاتجاهات، الإلغاء قبل القبول مع استرجاع كامل، التقييم.
- Around Social: «أتابعهم» و«لك»، إعجاب وتعليق وحفظ ومشاركة، متابعة، ملف شخصي، بلاغ، و«اطلب نفس الطلب» من أي منشور أو ستوري.
- كاميرا مثل سناب وإنستغرام: عدسات (عادي، ملصق المحل، إطار Around)، فلاش، قلب الكاميرا، الألبوم، نص على الصورة، النشر في قصتي و/أو اكسبلور.
- الهدايا: مبلغ أو منتج من محل، لرقم هاتف أو حساب، مع رسالة ولون بطاقة. لو الرقم ما عنده حساب، تنضاف الهدية تلقائياً أول ما يسجّل.
- الولاء: عضوية برونزية وفضية وذهبية وبلاتينية حسب طلبات السنة، ونقاط كل محل حسب نظامه مع تاريخ الانتهاء.
- اكسبلور وخريطة المحلات، الإشعارات، سياراتي، تعديل الملف.

**تطبيق الفرع** (`/branch`): لوحة لحظية (جديد، قيد التحضير، جاهز) مع تنبيه صوتي، العملاء الجايين ووقت وصولهم، الواصلين مع لوحة السيارة بخط كبير، قبول أو رفض مع استرجاع تلقائي، فتح وإغلاق الفرع، إيقاف الأصناف.

**لوحة التاجر** (`/merchant`): نظرة عامة ورسم المبيعات، الطلبات، المنيو مع الصور، الفروع وأوقات الدوام والموقع، برنامج الولاء (أختام أو نقاط، الهدف، المكافأة، الصلاحية) مع معاينة، الستوريات وتثبيتها مع عدد الطلبات اللي جت منها، الموظفين، التسويات، ملف المحل.

**لوحة الأدمن** (`/admin`): مؤشرات المنصة، اعتماد التجار وطلبات الانضمام، العمولات، الطلبات، مراجعة البلاغات وحذف المحتوى، المستخدمين.

## البنية

```
server/   Node.js + Express + SQLite (better-sqlite3) + Socket.IO
  src/routes/     auth, stores, orders, social, gifts, branch, merchant, admin
  src/services/   orders (دورة الطلب والتتبع), payments, loyalty, social, stores, uploads
  src/seed.js     بيانات تجريبية (أسماء محلات وهمية)
  test/           اختبارات API شاملة (npm test)
web/      React + Vite، واجهة واحدة فيها التطبيقات الأربع والموقع
```

المبالغ محفوظة بالفلس (1 درهم = 100). الوقت حسب توقيت الإمارات.

## قبل الإطلاق الحقيقي

1. **بوابة الدفع**: الدفع حالياً في وضع تجريبي (`server/src/services/payments.js`). البطاقة `4000 0000 0000 0002` ترفض دائماً عشان تجرب حالة الرفض. نضيف محوّل للبوابة المختارة (N-Genius أو Telr أو Checkout.com أو Stripe) بنفس الواجهة، ونفعّل Apple Pay بشهادة التاجر.
2. **الرسائل النصية**: رمز التحقق ورسائل الهدايا تنطبع في سجل الخادم. نربط مزود SMS في `routes/auth.js` و `routes/gifts.js`.
3. **قاعدة البيانات والصور**: SQLite ممتازة للتجربة والبداية. للتوسع ننقل لـ PostgreSQL، والصور لـ S3 أو ما يشابهه (`services/uploads.js`).
4. **الإعدادات**: انسخ `.env.example` وغيّر `JWT_SECRET` وحط `NODE_ENV=production`.
5. **رصيد الهدايا**: قيمة مخزنة، تحتاج ترخيص أو شراكة مع جهة مرخصة (راجع وثيقة المنتج).
6. **تطبيقات المتاجر**: تطبيق العميل PWA يتثبت من المتصفح. لرفعه على App Store و Google Play نغلفه بـ Capacitor.

## الهوية والواجهة (Around)

- الاسم: **Around** — الشعار حلقة (المنطقة حولك) ونقطة تدور عليها (أنت وأنت قادم).
- الخط: Readex Pro (عربي حديث، يُحمَّل محلياً من الحزمة بدون Google Fonts).
- الأيقونات: Phosphor فقط (بدون إيموجي). شعار المحل = أيقونة نوعه، والصورة الشخصية = أيقونة.
- نظام التصميم في `web/src/styles.css` (متغيرات الألوان والحركة في أول الملف)، وصفحة الموقع في `web/src/pages/site/`.
- مفتاح بيانات التطوير (Demo / Worst case / Empty) أسفل الشاشة، ويختفي مع `NODE_ENV=production`.
